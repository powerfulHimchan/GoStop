# GoStop

카툰풍 도트 그래픽을 사용한 안드로이드 선택형 이야기 게임입니다. 《내일도 달릴 수 있게》는 서울에 사는 준호가 열세 달 동안 일과 자신의 속도를 다시 찾아가는 이야기입니다.

- 그래픽, 텍스트, 선택 버튼 두 개로 구성한 플레이 화면
- 5막의 선택 50회, 여섯 분류의 엔딩 14개와 경로에 따라 달라지는 후일담
- 선택으로 얻은 아이템에 따라 달라지는 이후 행동과 언제든 열 수 있는 소지품 메뉴
- 엔딩마다 실제로 내린 결정 중 결말에 영향을 준 두세 가지 선택과 그 결과 표시
- 선택 자동 저장과 이어하기, 엔딩에서 원하는 막의 첫 선택으로 돌아가기 또는 처음부터 시작

장면과 선택지는 `app/src/main/assets/story/scenes.txt`, 엔딩과 후일담은 `endings.txt`에 있습니다. 같은 선택 순서 안의 조건부 장면을 먼저 확인하고 마지막에 기본 장면을 사용합니다. 진행은 실제 선택을 순서대로 저장하며, 0.2.x의 다리 테스트 시나리오 저장과는 별개입니다.

## 실행

Android Studio에서 저장소를 열고 JDK 17 이상과 Android SDK 35를 설치한 뒤 `app`을 실행합니다. 명령줄에서는 다음과 같이 디버그 APK를 빌드합니다.

```sh
./gradlew :app:assembleDebug
```

APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. 실행에는 Android 6.0(API 23) 이상이 필요합니다.
