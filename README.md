# GoStop

카툰풍 도트 그래픽을 사용한 안드로이드 선택형 이야기 게임입니다. 《내일도 달릴 수 있게》는 준호가 서울의 야간 배송 사고 이후 일과 생활의 방향을 고르는 이야기입니다.

- 대기 중에도 움직이는 도트 장면, 텍스트, 선택 버튼 두 개로 구성한 플레이 화면
- 18번째 선택에서 네 경로, 37번째 선택에서 여덟 경로로 나뉘는 총 50회의 선택
- 여섯 분류의 엔딩 14개와 경로에 따라 달라지는 후일담, 본 엔딩만 다시 읽는 엔딩 모아보기
- 선택으로 얻은 아이템에 따라 달라지는 이후 행동과 언제든 열 수 있는 소지품 메뉴
- 엔딩마다 실제로 내린 결정 중 결말에 영향을 준 두세 가지 선택과 그 결과 표시
- 선택 자동 저장과 이어하기, 엔딩에서 원하는 막의 첫 선택으로 돌아가기 또는 처음부터 시작

장면과 선택지는 `app/src/main/assets/story/scenes.txt`, 엔딩과 후일담은 `endings.txt`에 있습니다. 같은 선택 순서에서는 구체적인 소지품 조건을 먼저 확인하고, 해당 경로의 기본 장면을 사용합니다. 기존 스토리 진행 기록이 같은 앱에 남아 있으면 그 이야기에서 이어갈 수 있고, 새 분기 이야기는 별도로 시작할 수 있습니다.

## 실행

Android Studio에서 저장소를 열고 JDK 17 이상과 Android SDK 35를 설치한 뒤 `app`을 실행합니다. 명령줄에서는 다음과 같이 디버그 APK를 빌드합니다.

```sh
./gradlew :app:assembleDebug
```

APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. 실행에는 Android 6.0(API 23) 이상이 필요합니다.
